ONE-LINE INSTALL

ZERO CONFIG 
curl -fsSL https://raw.githubusercontent.com/haydermuhib/learn-duckdb/main/install.sh | bash
irm https://raw.githubusercontent.com/haydermuhib/learn-duckdb/main/install.ps1 | iex
uvx --from git+https://github.com/haydermuhib/learn-duckdb.git learn-duckdb
git clone https://github.com/haydermuhib/learn-duckdb.git
cd learn-duckdb && uv run app.py

Requires Python 3.11+. The installer automatically manages uv environments without polluting system packages.

CORE ARCHITECTURE

01

IN-MEMORY ISOLATION

Every lecture runs on an isolated in-memory DuckDB database (:memory:). Experiment, insert, and query without fear of corrupting source data.

02

RESULT-BASED GRADING

The engine tests your query's output schema and row contents rather than matching strict SQL strings. Write idiomatic SQL your way.

03

INTELLISENSE AUTOCOMPLETE

Native keyboard-friendly autocompletion for SQL keywords, aggregations, window functions, and active table column names with Tab.
